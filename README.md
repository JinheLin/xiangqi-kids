# 小棋探 · 儿童中国象棋入门课堂

面向零基础小朋友的简体中文互动 Web 应用。React + TypeScript + Vite，无需账号和后端，素材随源码提供，没有第三方字体、广告或分析请求。

在线课堂：**https://jinhelin.github.io/xiangqi-kids/**

## 本机启动

克隆仓库并进入项目目录，然后安装依赖：

```sh
git clone https://github.com/JinheLin/xiangqi-kids.git
cd xiangqi-kids
npm ci
npm run dev
```

打开终端显示的地址，通常为 http://127.0.0.1:5173/ 。默认只监听本机。固定使用同一个地址和端口，才能继续读取同一份浏览器学习进度。

首次在另一台机器安装：需要 Node.js 22.12+（本机验证环境为 22.22.0），执行 `npm ci`。如系统设置了代理，可以这样直连安装：

```sh
env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u http_proxy -u https_proxy -u all_proxy npm ci
```

## 已完成功能

- **5 章、22 课、42 个可操作任务**：认识 9×10 棋盘和红黑双方、辨认七种棋子，学习车马炮兵相仕帅的走法、蹩马腿、塞象眼、过河和九宫，学习吃子、将军、躲开/挡住/吃掉进攻者三种应将、将帅照面、将死与困毙。
- **真正操作棋盘**：点击棋子再点击落点；辨认题点击目标棋子；选择题观察棋盘作答。每课都有独立局面，所有走棋任务都由同一个棋规引擎校验。
- **分层教学**：具体错误原因、两级提示、安全落点标记、可重播的走棋演示、正确后的规则讲解。演示不会代替孩子通关。
- **奖励与成长**：逐课解锁、每课最多 3 星、每章一枚徽章；重复通关保留最好成绩，不重复累计奖励。独立无误完成得 3 星，使用提示或少量错误得 2 星，多次尝试仍可获得 1 星。
- **本地保存**：课程完成情况、最好星级、最近课程和语音偏好保存在当前浏览器；刷新恢复。数据损坏会安全恢复初始值，存储不可用会显示说明，同一来源的多个标签页能同步成绩。
- **自由练习**：完整初始棋局，入门电脑陪练（孩子执红、电脑执黑，确定性两层搜索）和双人同屏，可切换合法落点、获得一步提示、悔棋、查看走棋记录、重新开始。
- **棋子图鉴**：七种棋子的口诀和规则，显示当前局面的安全走法，快捷进入相应课程。
- **响应式和辅助操作**：桌面双栏、手机单栏，手机棋盘上方提供任务说明；棋盘支持方向键移动焦点与回车选择；实时反馈、跳至主内容、减少动态效果偏好。语音按钮可开启浏览器的中文朗读，是否有中文声音取决于系统与浏览器。

## 棋规与明确范围

规则参考世界象棋联合会的 [World Xiangqi Rules 2018，第一章](https://www.wxf-xiangqi.org/images/wxf-rules/2018_World_XiangQi_Rules_English2018.pdf)。引擎独立于课程和界面，支持：

- 9 条竖线、10 条横线，棋子放在交叉点，标准 32 子布局；红先黑后。
- 七种棋子的双方走法、挡路、马腿、象眼、炮架、过河和九宫限制；兵不后退且不升变。
- 吃子、不能吃己方棋子、不能将帅照面、不能走后让己方帅受攻击、被将军必须应将。
- 对手无合法走法时获胜：正在被将军是将死，未被将军是困毙。采用将死结束棋局，不直接吃掉将帅。

这是儿童基础教学应用，不是正式比赛裁判系统。没有长将、长捉、自然限着、计时或认输的完整比赛裁决；自由练习中同一局面出现三次会暂停，并明确提示为教学暂停，可悔棋或重开。电脑是入门棋搭子，目标是练习基本走法，不是高水平棋力。练习局面只在当前页面中保留，离开或刷新后新开一局。课程进度按课保存，中途退出一课后会从该课开头重新练习。

学习进度保存在 localStorage，不会跨设备、跨浏览器或跨端口同步。清除网站数据也会清除学习进度；成长页面提供二次确认的清空操作。

## 构建和验证

```sh
npm test
npm run build
npm run preview
```

`npm run build` 会先作严格的 TypeScript 检查，再构建到 `dist/`。构建脚本自动清除所有常见代理环境变量并设置 `NO_PROXY=*`；不执行 `make format`。构建完成后是纯静态站点，可以放在任意静态 HTTP 服务器上，hash 路由不要求服务器回退规则。请通过 HTTP 访问，不要双击打开 `dist/index.html`。

浏览器回归测试：

```sh
# 本机有 Google Chrome 时，无需额外下载浏览器
PLAYWRIGHT_CHANNEL=chrome npm run test:e2e

# 或使用 Playwright 自带 Chromium
npx playwright install chromium
npm run test:e2e
```

浏览器测试会自动启动测试服务器（5173），或复用同地址已有的开发服务器。覆盖桌面和 iPhone 13 尺寸，全套 22 课通关、逐课解锁、5 枚徽章、星级复习、防重复奖励、提示演示、具体错误反馈、进度刷新恢复、存储禁用与损坏恢复、电脑走棋、悔棋、双人模式、重开、响应式无横向溢出和键盘操作。测试使用独立临时浏览器，不影响用户浏览器的学习记录。

## 音效

内置九种短音效：选子、落子、吃子、答对、走错、提示、将军、通关/获胜和悔棋。落子是轻敲声，奖励使用短旋律，错误反馈采用柔和的下行提示；没有循环背景音乐。声音由浏览器在本地合成，不下载音频文件。

默认开启，右上角「音效」可独立开关，专注模式下也保留音效按钮。音效与语音讲解互不影响，开关会保存在当前浏览器，旧学习记录和星星会保留。首次声音响应点按或键盘操作，不在打开网页时自动播放；页面隐藏或离开课程时会停止当前音效。浏览器不支持音频或拒绝播放时，课程仍可正常使用。实际音量由设备媒体音量控制。

音频回归使用浏览器真实 AudioContext 检查输出信号，并验证静音、刷新恢复、专注模式、独立语音开关、不可用音频接口，以及九种声音的波形能量、淡出和无削波。

## OPPO Pad3 与触屏平板

横屏是主要使用场景。棋盘根据浏览器可用高度调整，1120×800、1400×1000 等横屏窗口可同屏看到完整棋盘和教学操作；棋盘交叉点保留至少 48 CSS 像素的触控区域。字体、提示、模式切换和主要按钮也为手指操作加大。

- 点棋子，再点落点；选中后有明确提示和「取消选择」，不用反复点小棋子。
- 在棋盘上滑动仍可滚动页面；长按、滑动、双指接触不触发走棋，保留浏览器双指缩放。
- 点击「专心下棋」可隐藏网页导航和次要信息，让棋盘更大；「退出专注」或键盘 Escape 可返回。不要求浏览器全屏权限。
- 横竖屏切换不会重新开局，选中的棋子、轮次、走棋记录和悔棋历史均保留。竖屏让棋盘占满宽度，讲解放在下方。
- 浏览器地址栏占用较多高度时，可使用专注模式；更小的窗口允许正常滚动，不把棋子缩到难以点击。

OPPO Pad3 的[官方显示规格](https://www.oppo.com/en/accessories/oppo-pad-3-matte-display-edition/specs/)为 2800×2000；显示缩放、地址栏与多窗口会影响实际网页可用尺寸，因此适配依据 CSS 可用宽高与触屏能力，不把物理分辨率写死成页面尺寸。

浏览器测试提供四种平板模拟：1120×800、1400×1000、1120×720（模拟地址栏占用）、800×1120（竖屏）。这些是 Chromium 触屏模拟，不代表已在 OPPO 真机上测试。覆盖轻点选子、取消、错误反馈、滑动、长按、双指接触、旋转后保留棋局、专注模式和触控目标尺寸。

```sh
PLAYWRIGHT_CHANNEL=chrome npm run test:e2e -- --project=oppo-pad3-landscape
```

## GitHub Pages 部署

仓库的 `main` 分支每次推送都会运行 `.github/workflows/pages.yml`：安装锁定依赖、运行单元测试、执行生产构建，同时验证桌面、手机和平板触屏操作；全部通过后再部署至 GitHub Pages。也可以在 Actions 页手动运行工作流。

GitHub Pages 使用 GitHub Actions 作为发布来源。工作流为构建设置 `BASE_PATH=/<仓库名>/`，避免项目子路径下的脚本、样式和图标出现 404。本地开发默认仍使用 `/`，页面采用 hash 路由，刷新课程地址不需要服务器回退配置。

在本机验证同样的发布路径：

```sh
BASE_PATH=/xiangqi-kids/ npm run build
npm run preview
# 打开 http://127.0.0.1:4173/xiangqi-kids/
```

线上进度保存在 GitHub Pages 所在浏览器的本地存储中，与本地开发地址的进度分别保存。

## 源码结构与扩展

```text
src/engine/xiangqi.ts             纯棋规、局面转换、胜负判断、入门陪练
src/engine/xiangqi.test.ts        棋规边界与每一个课程局面的合法解法验证
src/data/curriculum.ts           章节、课程、任务、初始局面、提示与讲解
src/progress.ts                  进度格式、校验、解锁、最高星级
src/progress.test.ts             保存恢复、坏数据、解锁、防重复奖励
src/components/Board.tsx         SVG 棋盘与可键盘操作的交叉点
src/components/LessonPlayer.tsx  课程状态、逐步反馈、提示和演示
src/components/Practice.tsx      自由对局、电脑回合、历史与悔棋
src/components/Art.tsx           本地 SVG 插画、图标与星星
src/App.tsx                      学习地图、图鉴、成长和页面入口
src/styles.css                  桌面、平板与手机样式
tests/app.spec.ts               桌面/手机的浏览器回归
```

新增课程时，在 `curriculum.ts` 的 `lessons` 中增加唯一的稳定 ID，指定章节、标题和任务列表。任务支持 `identify`（辨认）、`quiz`（选择）和 `move`（真实走棋）。走棋任务提供 `board`、`from`、`to` 和 `turn`，可标注期望结果 `capture/check/escape/checkmate/stalemate`。所有教学局面应包含合法的双方将帅。新增任务会自动进入课程解法测试，防止出现无解关卡；修改已发布课程时保留原有 ID，以兼容已有本地进度。

本机启动命令、源码和生产构建都已经实际验证。


### 移动端应用体验

- 触摸设备使用占满可用屏幕的应用框架：OPPO Pad3 横屏为左侧导航，手机和竖屏为底部导航。导航固定，内容在当前屏幕内滚动，适应浏览器地址栏与安全区。
- 平板横屏的课程和练习采用固定棋盘、独立滚动讲解区；手机和竖屏有“看棋盘 / 讲解与提示”或“练习工具”快捷入口。手机答题及反馈会自动进入视野。
- 当前浏览器标签页内，切换栏目和前进、后退会保留地图展开章节与滚动位置、棋子图鉴选择、未完成课程任务与提示、自由练习棋局和悔棋记录。离开练习会暂停电脑陪练，返回后继续；离开课堂会停止语音及演示。
- 完成的课程重新进入时可以重新挑战。课程星星和音效设置仍使用原来的本地保存方式；刷新页面会重新开始当前棋局和未完成任务。
- `tests/shell.spec.ts` 验证固定导航、无整页刷新、位置与棋局保留、系统前进后退、隐藏页面暂停陪练、窄屏课堂定位和横屏讲解单独滚动。


### OPPO Pad3 横屏工作区

- 学习地图改为同屏的章节栏和课程列表，五章入口一直可见，仅课程列表内部滚动；手机和桌面仍保留各自适合的布局。
- 棋子图鉴也采用同屏观察板与说明，七种棋子的选择和进入课程按钮固定。
- 横屏课堂的进度、底部提示/演示和下一步按钮固定，题目、选项和解释在中间滚动；使用提示或答题后，反馈会进入视野，棋盘保持原位。
- 练习场可切换“练习助手”和“走棋记录”，悔棋与提示一直保留。走错时自动回到助手，重开采用可取消的对话框。
- 支持的浏览器显示“全屏使用”，点按后可暂时收起浏览器栏，退出全屏不会重开棋局。浏览器拒绝或不支持全屏时仍可正常学习，不锁定屏幕方向。
- 识别棋子的提示只原地发光，不缩放点按区域。工作区测试覆盖全部 22 课的 42 个任务、提示与反馈同屏、章节切换、全屏实际进入/退出、全屏不可用和旋转屏幕。
